# 骰子机器人系统

## 项目简介
骰子机器人是一个基于微信的多功能聊天机器人，集成了骰子投掷、牌堆抽卡、天气查询、AI聊天和角色卡管理等功能。适用于桌面角色扮演游戏（TRPG）和日常聊天场景。

## 主要功能
### 🎲 骰子系统
- 支持复杂骰子表达式（如`2d20k1+3d6dl1`）
- 优势/劣势投掷（a/p标记，如`d20a`优势骰，`d20p`劣势骰）
- 支持复合运算（如`d8*(d4+2)`）
- 支持重复投掷（如`d4:d6`）
- 多面骰支持（d4/d6/d8/d10/d12/d20/d100）

### 🃏 牌堆系统
- 内置多种牌堆（108将、万象无常等）
- 支持自定义牌堆（JSON/TXT格式）
- 108将牌堆支持图片展示

### 🌤️ 天气服务
- 实时天气查询
- 72小时天气预报
- 灾害预警通知
- 生活指数（穿衣/运动/紫外线）
- 定时天气播报

### 🤖 AI聊天
- 通义千问集成
- 多会话管理
- 群聊/私聊权限控制
- 定时消息推送

### 🔮 今日人品
- 从64卦中随机抽取一卦
- 附带卦象图片和诗句解释
- 每人每天仅能抽取一次

## 角色卡管理系统

### 基础命令
- `.char help` - 显示帮助信息
- `.char load` - 上传角色卡文件
- `.char list` - 显示所有可用角色卡
- `.char info [角色名]` - 显示角色卡信息
- `.char use <角色名>` - 使用指定角色
- `.char release` - 释放当前使用的角色
- `.char history [角色名]` - 显示角色卡操作历史
- `.char force release <角色名>` - 强制释放被占用的角色（仅管理员可用）

### 技能检定与成长系统
- `.c <技能名>` - 对指定技能进行检定
- `.grow <技能名> [次数]` - 对指定技能进行成长检定
- `.grow history [角色名] [显示条数]` - 显示角色的技能成长历史
- `.setgrow <角色名> <点数>` - 设置角色的成长点数（仅管理员可用）

### 使用说明
1. **角色卡使用规则**
   - 每个用户同一时间只能使用一个角色
   - 使用新角色前需要先释放当前角色
   - 一个角色同时只能被一个用户使用

2. **技能成长规则**
   - 成长检定使用D100，需要投出大于当前技能值的结果
   - 成长值根据当前技能值决定：
     * 1-29: 1d10
     * 30-49: 1d8
     * 50-69: 1d6
     * 70-89: 1d4
     * 90+: 1d3
   - 投出100时获得双倍成长值
   - 技能值>95时，投出96-100总能成长
   - 每次成长检定消耗1点成长点数

3. **历史记录**
   - 系统会记录角色的所有操作历史
   - 包括创建、使用、释放等基础操作
   - 记录技能成长历史和成长点数变化

4. **注意事项**
   - 角色名如果包含空格，需要用引号括起来
   - 可选参数用[]表示，必填参数用<>表示
   - 技能名称大小写不敏感，但需要与角色卡中的名称匹配

## 快速开始
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 配置config.yaml：
   ```yaml
   ai:
     qwen:
       api_key: your_api_key
       app_id: your_app_id
   ```

3. 启动机器人：
   ```bash
   python main.py
   ```

## 使用示例
### 骰子指令
```
.r 2d20k1+3d6dl1    # 取2d20中较高的一个，加上3d6中除了最低的一个外的总和
.r d20a             # 投掷d20优势骰（投2次取高）
.r d20p3            # 投掷d20劣势骰3次（投3次取低）
.r d4:(d8+2)        # 先投d4获得次数N，然后重复计算(d8+2)共N次
```

### 技能检定和成长
```
.c 侦查             # 进行侦查技能检定
.grow 侦查          # 对侦查技能进行成长检定
.grow 侦查 3        # 对侦查技能进行3次成长检定
.grow history       # 查看当前角色的成长历史
```

### 天气查询
```
.weather 北京       # 查询北京当前天气
.weather 上海 3d    # 查询上海未来3天天气
```

### 抽卡指令
```
.draw dmt 2         # 从"万象无常"牌堆抽2张牌
```

### 今日人品
```
.jrrp               # 获取今日人品（卜一卦）
```

### AI聊天
```
@机器人 今天天气如何？    # 群聊中@机器人进行对话
```
